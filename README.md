# Audio Cutter and Exporter

iPhone and iPad app that splits a long concert recording into individual songs, then exports them as numbered, tagged files for Apple Music.

- `AudioCutter/` – SwiftUI source
- `AudioCutter.xcodeproj` – open this in Xcode
- `docs/` – support and privacy pages (GitHub Pages)
- `AppStore/` – listing text and the sample recording for App Review
